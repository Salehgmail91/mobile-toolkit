# Mobile Toolkit

**جعبه ابزار کامل موبایل**  
محصول **Krypton Studio** — نسخه ۱.۲.۲

---

## معرفی

Mobile Toolkit اولین محصول رسمی شرکت **Krypton Studio** است.  
یک اپلیکیشن وب پیشرفته (PWA) با رابط کاربری فارسی و راست‌چین که بیش از ۲۰ ابزار سیستمی و کاربردی برای موبایل ارائه می‌دهد.

در حال حاضر شرکت محصول دیگری ندارد و سایت رسمی نیز راه‌اندازی نشده است.

---

## ویژگی‌ها

- ✅ رابط کاربری مدرن و کاملاً فارسی (RTL)
- ✅ تم تاریک / روشن
- ✅ قابل نصب روی صفحه اصلی موبایل (PWA)
- ✅ کار آفلاین (Service Worker)
- ✅ نسخه حرفه‌ای (Pro) با امکانات پیشرفته
- ✅ بدون نیاز به نصب از فروشگاه

### دسته‌بندی ابزارها

| دسته | ابزارها |
|------|---------|
| **دستگاه** | اطلاعات سخت‌افزار، باتری، صفحه نمایش، لرزش، تمام‌صفحه، Wake Lock |
| **شبکه** | وضعیت اتصال، IP عمومی، تست پینگ، DNS Lookup، User Agent |
| **سنسورها** | قطب‌نما، شتاب‌سنج، ژیروسکوپ / جهت‌گیری |
| **ابزار کاربردی** | ماشین‌حساب، تبدیل واحد، کرونومتر، Base64، JSON، URL Encode، هش |
| **امنیت** | تولید رمز قوی، بررسی قدرت رمز، UUID، OTP، SHA-256 |
| **رسانه** | انتخاب‌گر رنگ، تولید QR Code، پالت رنگ |

## نحوه استفاده

### روش ۱: باز کردن مستقیم

لینک را باز کنید:
https://salehgmail91.github.io/mobile-toolkit/

### روش ۲: نصب به عنوان اپ 
1. اپ را در مرورگر Chrome یا Safari موبایل باز کنید.
2. منوی مرورگر → **Add to Home Screen** / **افزودن به صفحه اصلی**
3. اپ مثل یک برنامه واقعی نصب می‌شود.

### روش ۳: سرور محلی
```bash
cd mobile-toolkit
npx serve .
# یا
python3 -m http.server 8080
```
